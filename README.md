# Patitas

Landing page para Patitas Spa Condesa, enfocada en servicios de spa, baño y grooming para mascotas.

## Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```

## Estructura

- `src/app`: layout, página principal y estilos globales.
- `src/components`: secciones de la landing y flujo de agenda.
- `src/styles`: módulos CSS por sección.
- `src/lib`: utilidades reutilizables, como presets de animación.
- `public/img`: imágenes usadas por la landing.
